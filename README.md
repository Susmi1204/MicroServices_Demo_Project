# Microservices Demo Project

A simple Spring Boot project demonstrating microservices architecture using Student Service and Course Service.

## 🛠️ Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST API
- RestTemplate and WebClient

## 📌 Features
- Manage student information
- Manage course information
- Communicate between Student Service and Course Service
- Retrieve course details through REST APIs

## 📂 Project Structure
- **student-service** – Manages student data
- **course-service** – Manages course data
- **Sql Queries.txt** – Contains SQL queries
